# Uma Sessão raiz, foco por projeto

No OpenCode v2 uma Sessão é presa a um diretório. Para manter a conversa contínua enquanto se navega entre projetos, a Sessão vive na raiz `Documents\Projetos` e o seletor apenas muda o Foco, injetando o caminho relativo no próximo Ditado. Sessões separadas por projeto fragmentariam o contexto e exigiriam juntar transcrições no app.
